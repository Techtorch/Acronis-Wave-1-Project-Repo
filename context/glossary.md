# Glossary

Definitions follow the SOW v4 where it defines the term.

| Term | Meaning |
|---|---|
| Wave 1 / Wave 1A | The first execution wave ("Establish Control") of the Commercial Operating Model roadmap, centred on F1 Sales Process and CRM Overhaul and extended to Leadership Assets and the CDW agentic pilot. Mobilisation Oct 5, 2026 to close Jan 15, 2027. |
| Wave 0 / 2 / 3 | Roadmap waves: Wave 0 Mobilize (weeks 0 - 2), Wave 2 Scale the Foundation (months 4 - 6), Wave 3 Extend and Optimize (months 6 - 12). Indicative timeframes. |
| F1 - F9 | The nine Commercial Operating Model initiatives: F1 Lead-to-Quote Operating Model and Salesforce Overhaul, F2 MSP Visibility Intelligence, F3 Data Infrastructure, F4 Quote-to-Cash Integrity, F5 KPI and Performance Certification, F6 Commercial Systems and Integration, F7 Lead-to-ARR Transparency, F8 Operating Model Certification, F9 Forecast Modernization. |
| Commercial Operating Model Diagnostic | The completed assessment phase that produced the findings, figures and roadmap behind Wave 1. |
| Workstream | One of the seven key areas of work in scope, each with a named Acronis Workstream Owner. |
| Stage / Stage Gate | One of four sequential execution periods (Design, Build and Pilot, Test and Cutover, SKO Launch and Adoption), each closed by a formal review where the named Acronis signer confirms readiness. |
| Forward-Deployed Engineering (FDE) | Delivery model where TechTorch team members work inside Acronis teams, building alongside Workstream Owners and the Salesforce platform team, while Acronis owns decisions and outcomes. |
| Design Authority | The Acronis Salesforce platform team led by Marulis Paun. Approves designs, co-builds from Week 1, and runs the system after each Stage Gate. |
| Program Owner | The Acronis executive accountable for the program, owning the decision log and RAID: Christiaan Franken, Head of Revenue Operations. |
| SteerCo | Steering committee (CEO, Program Owner, selected ELT and EQT members) for decisions and trade-offs, not status. |
| Stage Model | The governed set of lead and opportunity stages, each with documented entry and exit criteria, used consistently across all regions. |
| Live Duplicate Account | A duplicate Salesforce Account carrying its own active pipeline and / or ARR. The diagnostic found 620 within 1,840 reported duplicates. |
| Baseline | The measured starting value of each Wave 1 success measure, agreed by the Program Owner in Week 2. |
| Pilot Sellers | Practising sellers named by Acronis (by Week 7) who use the new process on live deals in the Pilot Week. |
| Pilot Week | Dec 14 - 18, 2026. Pilot Sellers work live deals; also the main end-to-end test. |
| Go / No-Go | Decision to release to production. First on Dec 24, 2026; second on Jan 1, 2027 only if the contingency window is used. |
| Contingency window | Dec 28 - 31, 2026, opened only if a critical issue is still open at the first Go / No-Go. |
| Go-Live | Jan 1, 2027: Wave 1 changes live in production for all sellers. |
| SKO | Acronis Sales Kick-Off events in the first two weeks of January 2027, used to launch the new process to every seller. |
| Leadership Assets | A small set of standard Salesforce dashboards and reports for the pipeline review, forecast call and top-deal review, alongside existing Tableau insight. Temporary until the integration layer is in place. |
| Telemetry | Basic usage and data-quality measures held in Salesforce, used to track seller and leader adoption. |
| Agentic Pilot / CDW pilot | One AI agent use case designed and tested with CDW as a real partner, led by Gaidar Magdanurov, staffed separately from the core workstreams. |
| CDW | Acronis partner taking part in the agentic pilot. |
| Leakage floor | The evidenced minimum quote-to-cash revenue leakage: $1.62M per year. The leakage control register is built against it. |
| Leakage control register | Prioritized controls and remediation actions against the leakage floor, each with an owner (Quote-to-Order, Week 8). |
| Fixed capacity | Commercial model: one dedicated team for a fixed weekly fee; Acronis re-prioritizes within capacity without Change Orders. |
| Change Order | Formal written change, needed only to change duration, add objectives outside Wave 1, or where a capacity change cannot be agreed. |
| RAID | Risks, Assumptions, Issues and Dependencies log, owned by the Program Owner. |
| MSP | Managed Service Provider, Acronis' core partner channel (~21,000 partners). |
| ARR | Annual Recurring Revenue. Acronis ambition: double to $1B. |
| L2Q / L2C | Lead-to-Quote / Lead-to-Cash. |
| CPQ | Configure-Price-Quote tool. Acronis does not use one; selecting or implementing one is out of scope. |
| LeanData | Routing tool used for lead and opportunity assignment; in scope for routing configuration. |
| Acumatica | Acronis ERP / billing system; out of scope for change in Wave 1. |
| EQT | Acronis' private equity owner. |
| Torchbearers | TechTorch's roster of 11 delivery-role agents (Spark, Kindle, Ember, Flare, Lantern, Forge, Crucible, Ignition, Hearth, Afterglow, Watchtower) used as playbooks on this engagement. |
